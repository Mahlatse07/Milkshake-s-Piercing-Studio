
Changelog - Milkshake's Piercing Studio

Version 1.0 - Initial Website
1. Created the website structure using HTML.
2. Added the main website pages and navigation links.
3. Added images and website content.

 Version 2.0 - CSS Improvements
1. Created and linked an external CSS stylesheet.
2. Improved the website layout, colours, typography and styling.
3. Added responsive styling for different screen sizes.

 Version 3.0 - JavaScript and Functionality
1. Added a live date and time display to all website pages.
2. Added gallery category filters and an image lightbox.
3. Added an interactive FAQ accordion to the aftercare page.
4. Added search functionality for piercing services and jewellery.
5. Added dynamic jewellery listings, category filters and sorting.
6. Added an interactive map to the contact page.
7. Added JavaScript validation and AJAX submission for the contact and enquiry forms.

 Version 4.0 - SEO and Accessibility
1. Added page titles and meta descriptions to the website pages.
2. Added viewport meta tags for mobile-friendly display.
3. Added alternative text to images.
4. Created `robots.txt` and `sitemap.xml` files.

 Version 5.0 - Documentation
1. Created a README file describing the project, technologies and features.
2. Created this changelog to document the website's development.

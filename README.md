
 Milkshake's Piercing Studio Website

 Project Description
Milkshake's Piercing Studio is a website developed to showcase a fictional professional piercing studio based in Tembisa, South Africa. The website provides information about piercing services, jewellery, aftercare, appointments and contact details.

 Technologies Used
1. HTML5 – Website structure and content.
2. CSS3 – Website styling and responsive design.
3. JavaScript – Interactive website features and form validation.
4. Leaflet – Interactive map.
5. Formspree – Form submission handling.

Website Features
1. Multiple pages with navigation links.
2. Current date and time display.
3. Gallery with category filters and an image lightbox.
4. Search functionality for piercing services and jewellery.
5. Dynamic jewellery listings with category filters and sorting.
6. Frequently Asked Questions accordion.
7. Interactive map showing the general Tembisa area.
8. Contact and enquiry forms with validation.
9. SEO meta descriptions and mobile viewport settings.
10. Image alternative text for accessibility.

 Website Pages
1. Home
2. About Us
3. Piercing Services
4. Jewellery
5. Gallery
6. Aftercare
7. Booking
8. Contact
9. Enquiries

Project Structure
The project contains HTML pages, a CSS folder, a JavaScript folder, an Images folder, and SEO configuration files.

 How to View the Website
1. Open the project folder in Visual Studio Code.
2. Open the Home page using Live Server.
3. View the website in a web browser.
